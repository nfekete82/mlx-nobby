# MLX Nobby 1.10.0 — Media Library

The chat sidebar gains a **Bibliothek** entry and a full-width, responsive
gallery for images, videos, and Talking Photo clips generated by Nobby.

## What is included

- Filter by images or videos (Talking Photo is included under videos).
- Local visual previews (PNG / MP4), date, file opening, and download.
- Search by asset ID, media type or date.
- Explicit **keep permanently** on one file or all currently visible files;
  permanent delete only after user confirmation.
- Newly completed **normal chat images/videos** and directly generated images
  are now registered as persistent by default, so they remain available in the
  library until explicitly deleted. Talking Photo intermediate video outputs
  remain temporary; Shorts project outputs retain their existing durable
  lifecycle.
- Existing files are indexed *without moving or duplicating them*, as long as
  they are still in the managed output roots and have valid asset IDs.
- Pure local-only API. Index responses do not reveal user filesystem paths,
  prompts, or images embedded as base64. No cloud services.

## Important retention details

The old 24-hour cleanup policy applied to temporary generated assets; **new
normal chat media is now retained**. This can consume disk space over time,
so the user must be able to delete unwanted results. Existing files already
deleted by the old retention policy cannot be recovered.

Existing temporary assets that have not expired can be kept from the
library individually or using "Alle dauerhaft behalten". Merely viewing the
gallery doesn't silently promote old temporary files to persistent state.

## Security

Library IDs are validated against the existing trusted
`media_lifecycle._validate_id` contracts. Files are only listed from known
output roots, path traversal and symlinks are excluded, and save/delete use
those same canonical IDs. Explicit destructive action is confirmed in the
browser. The already existing local-access middleware remains active.
