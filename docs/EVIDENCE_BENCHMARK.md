# Evidence benchmark (synthetic v1)

The harness runs **60 deterministic synthetic scenarios** against
`audit_numerical_claims` and `gate_numerical_claims`. It never queries
the internet or invokes the local model.

## Commands

```bash
python -m pytest tests/test_evidence_benchmark.py tests/test_claim_validation.py tests/test_claim_context.py tests/test_evidence_repair.py -q
python -m agent.evidence_benchmark > evidence-benchmark.json
```

The JSON contains case-level expectations, flags and durations (milliseconds),
plus a confusion matrix (TP, FP, FN, TN), precision, recall, false-positive
rate, false-negative rate and the local audit latency. Rates describe
**detection of synthetic intentionally problematic claims**, not real-world
factual correctness.

Categories (ten scenarios each):

- supported: product and price appear in the same source context.
- unsupported: price absent from the source.
- other_product: price belongs to another named product.
- conflicting: two opened articles carry different nearby prices.
- no_fetch: no article loaded, so the audit is skipped.
- undated_prediction: qualitative prediction with no target numbers.

## Interpretation and constraints

- These cases are generated by code and are **not** a curated live
  hallucination dataset.
- A number near a model name is not semantic entailment.
- Same-device price variation may reflect currency, configuration, region,
  tax, or date rather than a true contradiction.
- Absence of a warning must **not** be called independently verified.
- Latency here measures the deterministic audit locally, **not** live model
  repair latency, model token throughput, network time, or end-to-end agent time.
- The benchmark does **not** assess primary-source authority, temporal
  relevance, semantic evidence, or quality of a rewritten answer.
- A controlled live dataset with manually adjudicated reference evidence is
  required before any claim of general hallucination reduction.
